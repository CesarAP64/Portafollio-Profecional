# CAP — Portafolio web

Primera versión funcional desarrollada desde cero con HTML, CSS y JavaScript.

## Ver localmente
Abre `index.html` en el navegador, o utiliza la extensión Live Server de Visual Studio Code.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `portafolio-cap`.
2. Sube el contenido de esta carpeta a la raíz del repositorio.
3. En Settings > Pages, selecciona Deploy from a branch, rama `main`, carpeta `/(root)`.
4. Espera a que GitHub Pages publique el sitio.
